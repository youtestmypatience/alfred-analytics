# Глоссарий Data Vault / DWH

- **Business Key (BK)** — бизнес-идентификатор сущности, область уникальности которого должна быть явно определена.
- **Hash Key (HK)** — детерминированный хеш нормализованного бизнес-ключа.
- **Hashdiff** — хеш набора описательных атрибутов для обнаружения изменений.
- **Hub** — таблица бизнес-идентичностей с метаданными загрузки.
- **Link** — таблица отношений между бизнес-идентичностями.
- **Satellite** — таблица исторических описаний Hub или Link.
- **Raw Vault** — зона интегрированной исторической информации с минимальной бизнес-интерпретацией.
- **Business Vault** — зона производных данных и изменяемых бизнес-правил.
- **PIT** — структура с указателями на версии Satellite по snapshot-date.
- **Bridge** — производная структура для ускоренного прохождения отношений.
- **CDC** — Change Data Capture, получение изменений источника.
- **Idempotency** — отсутствие дополнительного логического эффекта при повторе той же операции.
- **Grain** — смысл одной строки таблицы или факта.
- **SCD** — Slowly Changing Dimensions, способы обработки изменений измерений.
- **Valid Time** — период действия факта в предметной области.
- **Load Time** — момент загрузки/фиксации данных в определённом контуре.
- **Lineage** — путь происхождения и преобразований данных.
- **DAG** — ориентированный ациклический граф зависимостей.
- **Data Mart** — предметная аналитическая витрина.
- **EDW** — корпоративное хранилище аналитических данных.
